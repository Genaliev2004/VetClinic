# Этап 8. Проверка одногруппником

Проверяющий разворачивает проект у себя **только по README**, без помощи
автора. Достаточно одной ОС и одной СУБД.

## Что нужно проверяющему

* Git, JDK 17 или новее (`java -version`).
* PostgreSQL 14+ **или** Microsoft SQL Server 2019+ (с `sqlcmd`).
* Доступ в интернет при первой сборке: Maven Wrapper скачает Maven и драйверы.

## Порядок проверки

1. Клонировать репозиторий (ссылка — в README).
2. Создать БД скриптом из раздела «Развёртывание» README и убедиться, что тест
   ограничений выдал `PASS = 34, FAIL = 0`.
3. При необходимости поправить `config/db.properties`: пароль, порт, имя
   экземпляра SQL Server. Лучше сделать это в `config/local.properties`.
4. Собрать с тестами: `scripts\build.bat test` или `bash scripts/build.sh test`.
5. Запустить приложение и пройти сценарии M01, M03, M08, M11, M13–M15 из
   `docs/05_test_plan.md`.
6. Заполнить протокол ниже. Каждое затруднение — это дефект README или
   проекта; автор исправляет его и отмечает исправление в таблице.
