# Этап 0. Заявка темы на форуме

**Тема проекта: «Информационная система ветеринарной клиники „ВетКлиник“»**

Приложение на Java (Swing + JDBC) для учёта работы ветеринарной клиники. Клиенты
(владельцы) приводят питомцев на приём к врачам разных специализаций; на приёме
врач ставит диагноз и оказывает платные услуги, по приёму формируется счёт.

Пользователи (роли):

* **Администратор** — ведёт справочники: виды животных, специализации, врачи,
  услуги и их текущие цены; смотрит отчёты (выручка врачей, популярные услуги).
* **Регистратор** — регистрирует владельцев и питомцев, записывает питомца на
  приём к свободному врачу (слоты по 30 минут), отменяет запись, печатает счёт.
* **Врач** — видит своё расписание, проводит приём: вносит диагноз и
  оказанные услуги.

Отличия от похожих тем: учитывается история болезни каждого питомца, сервер БД
сам не даёт записать к одному врачу двух пациентов на одно время, услуга
в приёме хранит цену на момент оказания (прайс можно менять, старые счета
не «плывут»), запрещён возврат приёма из статусов «Проведён»/«Отменён».

СУБД: **PostgreSQL** и **Microsoft SQL Server** (приложение переключается между
ними через файл настроек `config/db.properties`).

Предварительный перечень таблиц (8):

| № | Таблица | Назначение |
|---|---------|------------|
| 1 | `species` | Вид животного (справочник) |
| 2 | `owner` | Владелец питомца |
| 3 | `pet` | Питомец |
| 4 | `specialization` | Специализация врача (справочник) |
| 5 | `vet` | Врач |
| 6 | `service` | Услуга клиники и её текущая цена |
| 7 | `appointment` | Приём (запись к врачу) |
| 8 | `appointment_service` | Услуги, оказанные на приёме (разрешение связи M:N) |
